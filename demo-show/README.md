# 啤酒节智能营促销系统 Demo Show 专项

## 项目目标

围绕活动标题“平凯 Loop Workshop：体验 Agent Team 带来的高效开发方式”，专项设计、实现和验证一套可现场演示的“啤酒节智能营促销系统”。

本项目同时验证两条闭环：

1. **Loop 研发闭环**：需求 → Agent Team 分工 → 任务执行 → Artifact / Checkpoint → Review → 发布 → V2 迭代；
2. **智能经营闭环**：经营异常 → 促销建议 → 规则校验 → 人工审批 → 执行 → 自动暂停 → 实验评估。

## 贯穿场景

演示时间来到晚高峰：

- A 区热门摊位平均排队 22 分钟；
- B 区客流低于同时间段基线 35%；
- B 区餐饮文创组合库存 420 份；
- 当前促销预算只剩 6000 元。

系统需要生成受客群、预算和库存约束的错峰促销，经人工审批后执行，并在库存、退款或预算达到阈值时自动暂停。最后通过实验组和对照组判断活动是否产生增量。

以上为演示假设，不代表真实啤酒节经营数据。

## 项目原则

- 以 Loop Agent Team 协作效率为主角，业务系统是可验收的任务载体；
- Agent 数量少而清晰，不用 Agent 数量制造“繁忙感”；
- 明确 `@beerfest-dev-team` 才是一次正式派工；
- 一个项目根任务承载同一个交付物，子任务承载实现、测试和增量迭代；
- Developer 不能自己宣布成功，Reviewer 必须提供独立测试证据；
- 人负责范围、风险和发布决策，Agent Team 负责执行和交付；
- 基础骨架可以预置，但现场实际完成内容必须透明；
- 经营数据分为公开事实、演示假设、现场实测和规划目标；
- 不预设“提效 10 倍”或经营 ROI，使用现场实际时间、任务、Review 和人工介入进行说明。
