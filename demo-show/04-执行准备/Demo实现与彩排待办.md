## 8. 进入正式彩排版的门槛

只有同时满足以下条件，才能把 V2 Script 升级为“正式彩排版”：

1. Agent Team 与任务 Review 链路在活动版本验证；
2. V1、经营工作流和 V2 至少连续成功 3 次；
3. 失败 Checkpoint 可以真实恢复；
4. 35 分钟版最长彩排时间不超过现场窗口；
5. 所有模拟数据、公开事实和现场实测标识清楚；
6. 主持人能够在 Agent 等待期间继续讲解而不重复；
7. 演示账号、机器、网络、模型和预览环境已经冻结。
