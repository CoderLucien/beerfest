4.2 验收门禁

指标阈值不通过时的处理
L1 数据精确匹配率≥ 95%逐条排查 FAIL，修复后重跑全部 A 类用例
L2 分析可接受率≥ 80%分析 FAIL 项反馈 RD 调整 prompt/template
L3 防虚构率100%（不可妥协）任何虚构 → 阻塞上线，必须修复
意图分类准确率≥ 90%低于阈值需调整路由规则
确定性问题 p95 延迟< 1000ms排查 SQL 查询性能或网络延迟
前端 UI 用例通过率100%渲染异常 → 阻塞上线
回归用例通过率100%任何回归 → 阻塞上线
